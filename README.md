# Manajemen Mahasiswa - Double Linked List

Project ini adalah implementasi Sistem Manajemen Data Mahasiswa menggunakan struktur data Double Linked List dengan bahasa Python.

## Fitur
- Tambah data mahasiswa (NIM, Nama, Jurusan)
- Tampilkan data dari depan dan belakang
- Hapus data mahasiswa
- Cari data mahasiswa
- Sorting data

## Struktur File
- `linked_list.py` - Logika Double Linked List
- `main.py` - Program utama & menu

## Cara Menjalankan
```bash
python main.py
'''
